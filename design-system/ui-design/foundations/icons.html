Foundations

Icons

An original set drawn for Anoglobe on a 24 pixel grid with round caps and joins. Every icon with an outline carries the same signature: a 2 pixel notch cut into its primary shape.

Usage

Reference a symbol by name and size it with a class. Stroke weight, notch size and detail level adjust per size, so a 16 pixel icon is drawn heavier and simpler than a 32 pixel one.

<svg class="a-icon a-icon--20" aria-hidden="true"><use href="#invoice"></use></svg>
  • Variants: #name for line, #name-duo for duo, #name-fill for fill.
  • Sizes: a-icon--16, a-icon--20, default 24, a-icon--32, a-icon--48.
  • Icons inherit currentColor. Decorative icons get aria-hidden="true"; icon-only buttons need an aria-label.
  • Each page carries the symbols it uses in a hidden sprite at the end of <body>, written by tools/sync-shells.mjs. This keeps icons working when a page is opened straight from disk, where browsers block external sprites. Icons created by scripts list their names in data-icons.
  • Standalone files live in assets/icons/svg/ as name.variant.size.svg. New icons are added in tools/icons/definitions.mjs and built with node tools/build-icons.mjs.
