Foundations

Logo

An original mark and wordmark, ready to swap if Anoglobe supplies an official logo.

Versions

Full color on light surfaces, reversed on dark. Mono versions for single color print and stamps.

Mark and favicon

The mark is a globe cut by a ledger line, with the notch every Anoglobe icon carries. The favicon sits on a mist tile so it reads on any browser tab.

Clear space and size

Keep clear space equal to the mark's ledger line height on every side. Minimum width 120 pixels for the full logo, 20 pixels for the mark.

Rules

Keep the logo intact.

  • Use the files in assets/img. Do not redraw, recolor, stretch or add effects.
  • Use the reversed version on dark surfaces and photos, never the full color one.
  • Pages reference assets/img/logo.svg, so an official logo can replace it in one place.
  • This logo is an original placeholder by the design team. If Anoglobe has an official logo, it replaces this one.
