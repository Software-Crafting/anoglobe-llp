Foundations

Colors

Mist is the neutral base for every surface, line and text color. Teal is the single accent for links, focus and highlights. Status colors are used only to communicate state.

Rules

How to apply color in new work.

  • Use semantic tokens in components and pages. Raw hex values live only in tokens.css.
  • Primary actions are deep Mist. Teal is for links, focus and small highlights, never large fills.
  • Never rely on color alone. Pair status colors with an icon or a text label.
  • Prefer a 1px border over a shadow. Shadows are reserved for popovers, dialogs and toasts.
  • Check every change in both themes and run the contrast check before committing.
